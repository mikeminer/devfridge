ANDROID 9+

จากดาวน์โหลดสู่เกมแรก

  1. 01

    ตรวจสอบโทรศัพท์

    ต้องใช้ Android 9+ พร้อม Android System WebView รุ่นล่าสุด อินเทอร์เน็ต และ OpenGL ES 3.0 ยังไม่รับประกันประสิทธิภาพบนอุปกรณ์ของคุณ

  2. 02

    ติดตั้งเบตา

    ดาวน์โหลด APK จาก GitHub หากระบบร้องขอ ให้อนุญาตเบราว์เซอร์นี้ติดตั้งแอป แล้วถอนสิทธิ์หลังติดตั้ง เปิด Play Protect ไว้

  3. 03

    เชื่อมต่อกระเป๋า Solana

    ใช้กระเป๋าที่รองรับ MWA ต้องมีอายุอย่างน้อย 18 ปี และล็อกโทเคนของตัวละครที่เลือกอย่างน้อย 500,000 โทเคนอยู่ แอปไม่ซื้อหรือล็อกโทเคนแทนคุณ

ติดตั้งรุ่น debug อยู่แล้วหรือไม่

ใบรับรองต่างกัน จึงอัปเดตด้วยเบตานี้ไม่ได้ การถอนการติดตั้งจะลบข้อมูลในเครื่อง กรุณาจัดการรายการลงทะเบียนที่ค้างและเก็บข้อมูลที่จำเป็นก่อน รุ่นถัดไปที่ลงนามด้วยคีย์เดียวกันสามารถอัปเดตเบตานี้ได้

SOLANA + ROBINHOOD

กระเป๋าของคุณ สองหน้าที่

01 / SOLANA

Solana / Seed Vault

อนุมัติข้อความในกระเป๋า Android เมื่อลงทะเบียนคะแนน ให้เลือก “Use game wallet · Seed Vault / Solana Mobile” ใน Phantom แล้วกลับมาในเกมเพื่อลงนาม

02 / EVM

Robinhood / Phantom

Phantom จัดการบัญชี EVM การอนุญาตใช้โทเคน และการชำระเงิน ตรวจสอบที่อยู่ ค่าธรรมเนียม และเครือข่าย ไม่จำเป็นต้องนำเข้าวลีกู้คืนของ Seed Vault

ก่อนชำระเงินสำหรับ TopShelf

การลงทะเบียนแบบชำระเงินเป็นทางเลือกและใช้เป็นทุนสำหรับรางวัลโทเคนตามฤดูกาลที่อาจมี เจ้าของสามารถถอนเงินที่ไม่ได้สำรองไว้ กำหนดการแจกจ่าย และปิดการรับรางวัลได้ ไม่รับประกันรางวัล กำหนดเวลา หรือการแจกจ่ายค่าธรรมเนียมทั้งหมด การตรวจสอบด้านกฎหมาย พื้นที่ และร้านค้ายังไม่เสร็จ เบตานี้ไม่ใช่การอนุญาตให้เข้าร่วมตามกฎหมาย
