ANDROID 9+

From download to your first run.

  1. 01

    Check your phone

    Android 9+, an up-to-date Android System WebView, internet access and a device supporting OpenGL ES 3.0. Performance on your device is not yet guaranteed.

  2. 02

    Install the beta

    Download the APK from our GitHub release. If Android asks, allow this browser to install this app, then turn that permission off again. Keep Play Protect enabled.

  3. 03

    Connect your Solana wallet

    Use an MWA-compatible wallet. Access is 18+ and requires an active lock of at least 500,000 tokens of the selected character. The app does not buy or lock tokens for you.

Already installed a debug APK?

The earlier debug build uses a different signing certificate, so Android cannot update it with this beta. Do not uninstall it while you still need saved runs: uninstalling clears local data. Resolve pending registrations first. Future updates signed with this release key can update the beta normally.

SOLANA + ROBINHOOD

Your wallets. Two clear roles.

01 / SOLANA

Solana / Seed Vault

Connect and approve messages through the Android wallet. For an optional score registration, choose “Use game wallet · Seed Vault / Solana Mobile” in the Phantom page and return to the game to sign.

02 / EVM

Robinhood / Phantom

Phantom handles the separate EVM account, token allowance and registration payment. Review the address, fee and network. No seed phrase needs to be imported from Seed Vault.
