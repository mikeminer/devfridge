# Build brief · 2026-09-22

Confirmed: cold-chain precision courier for a food/meme community; PASTA exact mainnet mint supplied by user; timelock unlocks a challenge course. User subsequently delegated amount/duration selection, seeking token-price benefits. Agent explained no access rule can ensure price support and selected a modest participation pilot instead.

Implementation: Fridge Run, a fixed camera miniature night market with a refrigerated three-wheeler. Collect six crates and return to the loading bay in 75 seconds (free practice) or 50 seconds (Night Shift challenge). Heat vents cost five seconds. Score = rounded remaining seconds × 100 + 600 on completion. Practice personal best persists locally; no ranked scores or rewards.

Art: original procedural enamel vehicle, split glazing, grille, lamps, rubber tyres/hubs, cargo box and rails; market stalls/awnings, signs, paving colour/relief, loading stripes, streetlights and crate markers. No World characters copied. Deliberately stylized miniature proportions with physically based material response, rather than a claim of photorealism.

Controls: arrows/WASD, Space brake, P/Escape pause; mobile directional pad and brake. Pointer capture and cancellation release controls. Dialogs/backgrounding pause; foreground requires manual resume. WebGL error/loss gets visible recovery text. Reduced-motion idle scene is still. Silent audio design.

Policy: 100 PASTA, six decimals, 100000000 raw; original >=86400 seconds; remaining >=60 seconds; sum independently qualifying same-wallet/same-mint vaults. No cross-mint aggregation. Access is rechecked on boundaries, foreground and at most 60-second intervals. API freshness maximum 90 seconds. Program/account proof and authenticated admission are separate future server responsibilities.

Modules: Three.js + direct Phantom provider + published read-only DevFridge API + official BigInt evaluator. No paid listings, swaps, new vault contracts, bridges, rewards, telemetry or unrelated ecosystem modules.

Hosting: local Vite preview. Public hosting and submission are not performed in this preparation session. Open-in-Phantom deep link becomes visible only at a public HTTPS origin. A real phone cannot reach this computer's loopback URL.

Open release work: physical phone/real Phantom tests; human art/playability review; public repository/HTTPS deployment and demo video; current program/security re-review before real deposit promotion. Local UI eligibility is bypassable and not claimed to be server authorization.
